# Confirmatory decision record

The authoritative protocol uses source-only development, a fixed 50-epoch all-source point refit, source-development residual scaling, and a 50:50 unlabeled target-adaptation/disjoint evaluation split. The target labels are used only for final scoring. Earlier all-target alignment and in-sample calibration experiments are superseded and are not included in this archive.

The CORAL-PCA-HGB control uses the same adaptation batch and source-label access as the assay-aware model. All predictions and figures are generated from the files in this archive.
